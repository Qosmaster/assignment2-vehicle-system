# Vehicle Management System

## Project Overview
This project demonstrates object-oriented programming concepts in Java, including inheritance, abstraction, composition, and aggregation.

## Class Hierarchy
- Vehicle (abstract superclass)
- Car, Motorcycle, Truck (subclasses)

Each subclass overrides abstract methods from Vehicle.

## Compilation and Run
javac *.java  
java Main

## Reflection
Inheritance simplified the design by allowing common vehicle behavior to be shared.
Method overriding allowed each vehicle type to define its own engine behavior.
Using protected fields required careful design to maintain encapsulation.
